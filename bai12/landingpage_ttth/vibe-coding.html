Chi Tiết Nội Dung Khóa Học Vibe Coding

  • Khái niệm Vibe Coding & sự thay đổi trong cách phát triển phần mềm hiện đại.
  • Cách tư duy theo bài toán thay vì viết từng dòng mã nguồn thủ công.
  • Giới thiệu các trợ lý AI hàng đầu dành cho coding (ChatGPT, Claude, Gemini, Antigravity AI, Copilot).

  • Giải mã Frontend (HTML/CSS/JS) – Giao diện hiển thị người dùng.
  • Backend & API – Xử lý logic và kết nối trao đổi dữ liệu.
  • Database – Nơi lưu trữ dữ liệu người dùng và hệ thống.
  • Khái niệm Deploy & Hosting – Đưa website lên mạng Internet toàn cầu.

  • Các bước chuẩn bị Prompt chi tiết (Context - System - User Request).
  • Quy trình thiết kế Wireframe & UI Layout bằng AI prompt.
  • Kỹ thuật giao tiếp và chỉ dẫn AI sinh ra mã nguồn sạch, chuẩn Responsive.

  • Cài đặt Visual Studio Code và các Extension hỗ trợ AI đắc lực.
  • Quản lý thư mục dự án: HTML, CSS, JS, Assets (Hình ảnh, Icon).
  • Sử dụng Terminal cơ bản để chạy dự án và quản lý thư viện.

  • Khái niệm Lưu trữ dữ liệu phía Client (LocalStorage, SessionStorage).
  • Hướng dẫn kết nối Database đám mây không mã nguồn (Supabase / Firebase / Mock API).
  • Thực hành lưu trữ form liên hệ và phản hồi của người dùng.

  • Kỹ thuật sử dụng AI để tìm và sửa lỗi (Debugging) cực kỳ nhanh chóng.
  • Kiểm thử giao diện trên nhiều thiết bị (Mobile, Tablet, Desktop).
  • Tối ưu tốc độ tải trang, hiệu ứng cuộn và UI/UX mượt mà.

  • Đưa website phát hành thực tế miễn phí qua GitHub Pages, Vercel, Netlify.
  • Trỏ tên miền tùy chỉnh (Custom Domain) cho trang web.
  • Kỹ năng thuyết trình, demo ứng dụng web chuyên nghiệp.

Mục tiêu sản phẩm đầu ra:

Mỗi học viên tự tay hoàn thiện và xuất bản một trang Landing Page thực tế theo mong muốn cá nhân (Giới thiệu dịch vụ, bán hàng, hoặc trang thông tin cá nhân Portfolio) hoàn chỉnh 100%.

  • Có giao diện đẹp mắt, tương thích Mobile & Desktop.
  • Có Form đăng ký thu thập dữ liệu khách hàng.
  • Đã được Deploy online với đường link chia sẻ thực tế.
