# Video Admin - Learning Project

## Đây là project gì?

Đây là project frontend-only để học:

- Vibe Coding
- Antigravity
- HTML
- CSS
- JavaScript
- CSV data
- localStorage
- CRUD
- Authentication simulation
- Dashboard charts

## Công nghệ

```text
HTML5
CSS3
Vanilla JavaScript
CSV
localStorage
```

Có thể dùng Chart.js CDN cho biểu đồ.

## Chạy project

Không nên mở trực tiếp:

```text
file:///...
```

Nên chạy local server.

Ví dụ với VS Code:

```text
Live Server
```

Hoặc Python:

```bash
python -m http.server 8000
```

Sau đó mở:

```text
http://localhost:8000
```

## Important

Đây là demo học tập.

Không sử dụng CSV/localStorage authentication cho production.

Nếu đưa lên production, nên chuyển sang:

- Backend API
- Database thật
- Password hashing
- JWT/session authentication
- Server-side authorization
- Secure file/video storage
